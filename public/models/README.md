# Modelos 3D del Companion

Los dos avatares incluidos en la V8 deben estar en esta carpeta:

- `companion-female.fbx`
- `companion-male.glb`

El visor selecciona automáticamente el formato correcto (FBXLoader/GLTFLoader). Los archivos son locales; no se depende de un modelo remoto.

Requisitos para el modelo definitivo: personaje ficticio adulto, licencia de uso comercial, materiales PBR y, preferiblemente, animaciones y blendshapes faciales.
