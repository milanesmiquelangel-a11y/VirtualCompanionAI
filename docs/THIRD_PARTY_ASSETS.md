# Third-party 3D assets

## Vitruvian human character

- Source: https://github.com/ibrews/VitruvianGodot
- Character: Vitruvian human, derived from CC0 Antonia Polygon / CharMorph Vitruvian.
- License: CC0 for the character, morphs/FACS blendshapes and textures, according to the source project's README and NOTICE.
- Runtime files:
  - vitruvian_body.glb
  - vitruvian_head.glb
  - vitruvian_hair_rigged.glb
- Purpose in this project: realistic female companion prototype, loaded from the source repository with a local fallback avatar.
- The source project also documents FACS facial blendshapes and speech visemes used for facial animation.

The project source and license information should be rechecked before any commercial release or redistribution if the upstream asset terms change.
